## 1. 背景与问题

现有 `/accounting` 已提供线上收入、线下收入、支出列表以及汇总统计卡片，但“统计分析”Tab 当前只有空状态。管理员还无法直观看到财务指标随时间的变化，也无法比较同一时间点的多项财务指标。

本需求是现有记账功能的后续增量，取代原 PRD 中“统计分析本期不实现”的阶段性边界；不改变已经实施的账单维护和汇总卡片规则。

## 2. 目标与非目标

### 2.1 已确认目标

1. 将“统计分析”Tab 定位为财务趋势分析。
2. 在 Tab 中提供一个以时间为 X 轴的趋势图表。
3. 图表视觉和交互参考 `/dashboard/models` 的“消耗分布”图表。
4. 图表右侧支持在柱状图和面积图之间切换。
5. 柱状图使用同一时间点多个并列 Bar 的分组柱状图，不使用堆叠柱状图。

### 2.2 待确认目标

- 暂无新的产品目标待确认；技术实现细节在开发计划中确定。

### 2.3 非目标

- 暂未确认增加第二个图表、排行、占比或明细钻取。
- 暂未确认引入模型调用量、Token、渠道成本等平台运营指标。

## 3. 用户与场景

- **用户角色**：管理员。
- **主要场景**：管理员按时间范围观察收入、支出和利润的变化，并在同一时间点比较多项财务指标。
- **权限边界**：沿用 `/accounting` 的管理员权限要求。

## 4. 功能需求

### 4.1 图表容器

- “统计分析”Tab 展示一个财务趋势图表。
- 图表容器不设置固定高度，应自适应填充页面统计卡片与工具栏之外的全部剩余高度。
- 容器结构和图表类型切换交互参考 `web/src/features/dashboard/components/models/consumption-distribution-chart.tsx`。
- 图表右侧提供“柱状图”和“面积图”切换入口。

### 4.2 坐标与系列

- X 轴固定表示时间。
- Y 轴表示人民币金额，使用现有记账页面的人民币金额格式。
- 同一图表包含总收入、总支出、毛利润三个财务指标系列。

### 4.3 柱状图

- 每个时间点按系列并列展示多个 Bar。
- 不启用 Stack，不将多个指标累加为一根柱子。
- 每个指标使用稳定且可区分的语义颜色，并通过图例和 Tooltip 同时传达含义，不能只依赖颜色。

### 4.4 面积图

- 支持与柱状图使用同一份时间序列数据切换展示。
- 面积图采用非堆叠形态（`stack: false`），三个系列分别绘制。
- 面积图的数据系列固定为总收入、总支出、毛利润；具体透明度和折线轮廓沿用现有图表视觉规范。

## 5. 数据与外部约束

### 5.1 已确认

- 数据基于现有记账模块的线上收入、线下收入和支出数据口径。
- 时间作为服务端聚合维度，具体粒度沿用现有筛选中的天、周、月候选项。
- 图表复用页面现有筛选条件：时间范围与统计卡片、表格一致；时间粒度使用筛选中的按天、按周、按月。
- 按当前时间粒度补齐筛选范围内的连续时间点；没有数据的时间点及指标按 0 展示。
- 保持用户选择的时间范围和时间粒度，完整展示时间点；当数据点超出可读宽度时，通过横向查看保证历史数据不被截断或自动改粒度。
- 柱状图必须为分组柱状图，而不是现有“消耗分布”中的堆叠柱状图。

### 5.2 技术设计阶段确定

- 图表数据接口是扩展现有统计接口还是新增趋势接口。
- 已确定技术口径：新增趋势接口，服务端负责补齐时间桶；使用服务端 `time.Local`，周从周一开始、月从一日开始；接口返回 `YYYY-MM-DD` 日期标签。全部范围按有效账单的最早至最晚时间补齐，显式范围按请求边界补齐；没有账单则显示暂无数据。
- 服务端与前端的连续时间点补齐职责。
- 金额展示沿用现有记账页面规则：Y 轴、Tooltip 和图例使用人民币 `¥`，保留两位小数；负数格式为 `¥-50.00`；Tooltip 按当前时间点列出三个系列。

## 6. 交互与状态

### 已确认

- 用户可在柱状图与面积图之间切换。
- 切换图表类型时保留当前时间范围和时间粒度。
- 默认图表类型为柱状图；本期不要求记忆上次选择。
- 图例支持点击显示/隐藏任意指标系列，初始默认三个系列全部显示；交互行为尽量复用现有图表组件的图例能力。
- 无数据时复用现有图表组件的空数据表现。
- 加载、错误和移动端适配沿用项目现有图表、React Query 和响应式布局规范。

### 技术设计阶段确定

- 图表类型切换、图例交互、Tooltip、横轴标签和横向查看的具体组件实现。

## 7. 验收标准

1. “统计分析”Tab 不再显示占位空状态，而是显示财务趋势图表。
2. 图表以时间为 X 轴，并按已确认的时间粒度聚合。
3. 用户可以切换柱状图和面积图，切换不会重置筛选条件。
4. 柱状图在同一时间点并列展示多个指标 Bar，不产生堆叠效果。
5. 三个系列为总收入、总支出、毛利润；图例支持多选显隐，金额显示为人民币两位小数，负数使用 `¥-数值`。
6. 缺失时间桶补零，长时间范围通过内置水平滚动条查看全部时间点，不改变粒度或截断数据。
7. 无数据、加载和失败重试使用既有图表/通用状态组件，其他三个 Tab 行为不变。
8. 趋势接口仅允许管理员访问，统计与现有卡片使用相同收入过滤口径。

以上验收均由开发者手动执行，AI 未运行验证。

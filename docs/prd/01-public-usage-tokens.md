# 公共 Token 用量接口 PRD

## 文档元信息

- 状态：已实现，待开发者验证
- 关联计划：`docs/plans/01-public-usage-tokens-plan.md`
- 最后确认范围：2026-09-14
- 当前已确认：接口免认证，返回全站所有用户的 Token 消费总量；日期、边界、校验、错误和限流规则已确认

## 1. 背景与问题

项目需要对外提供一个可直接访问的公共统计接口，用于按日期范围查询平台全站的 Token 消费总量，供外部页面、监控或数据展示使用。

## 2. 目标与非目标

### 2.1 目标

- 新增 `GET /api/public/usage/tokens` 公共接口。
- 接口无需登录、API Token 或其他认证信息。
- 按请求日期范围统计全站所有用户的消费 Token 总量。
- 返回稳定、可机器解析的 JSON 结构，包含统计日期和 `total_tokens`。

### 2.2 非目标

- 不返回用户、Token、模型、渠道等可识别明细。
- 不新增前端页面或管理配置。
- 不新增独立统计数据库或定时汇总任务。

## 3. 用户与场景

- 外部调用方：无需登录即可调用接口。
- 使用场景：公共用量展示、外部监控和平台数据集成。
- 前置条件：系统已配置并可访问主数据库；统计数据来源为现有 `quota_data` 聚合数据，不依赖消费日志的保留周期。

## 4. 功能需求

### FR-1 公共路由

- 方法：`GET`
- 路径：`/api/public/usage/tokens`
- 认证：免认证。
- 统计范围：所有用户的消费日志。

### FR-2 日期参数

- 请求参数：`start_date`、`end_date`，格式为 `YYYY-MM-DD`。
- 示例：`start_date=2026-07-01&end_date=2026-09-13`。
- `start_date` 与 `end_date` 均按自然日包含；例如请求 2026-07-01 至 2026-09-13，统计范围为 `[2026-07-01 00:00:00, 2026-09-13 23:59:59]`，响应原样返回 `end_date: "2026-09-13"`。
- 日期解析使用项目当前配置的统一时区。
- `start_date` 和 `end_date` 均为必填参数；缺少任一参数时返回参数错误。
- 单次查询最多覆盖 365 个自然日，超过时返回参数错误。

### FR-3 成功响应

目标响应结构：

```json
{
  "data": {
    "end_date": "2026-09-13",
    "start_date": "2026-07-01",
    "total_tokens": 17952374936
  },
  "message": "",
  "success": true
}
```

- `total_tokens` 表示日期范围内全站消费日志的输入 Token 与输出 Token 之和。
- `start_date`、`end_date` 按请求原值回显。
- 无消费日志时仍返回成功响应，`total_tokens` 为 `0`。
- `total_tokens` 为非负整数，技术实现必须使用能够承载大于 32 位结果的整数类型。

### FR-4 失败响应

- 日期格式错误、日期范围非法或查询失败时，返回项目现有统一错误响应。
- 沿用项目现有统一响应约定：成功和失败均返回 HTTP 200，通过 `success` 字段区分；错误响应包含 `message`，不公开数据库内部错误细节。

## 5. 数据与外部约束

- 现有 `model.QuotaData` / `quota_data` 表按小时聚合保存 `token_used`，数据写入主数据库。
- `quota_data.token_used` 的来源是消费请求的输入 Token 与输出 Token 之和。
- 公共接口使用主数据库中的 `quota_data` 聚合结果，不直接依赖 `logs` 表，也不受日志数据库 TTL 清理影响。
- 统计结果必须避免使用过窄的整数类型导致大数截断；`total_tokens` 使用能够承载大于 32 位结果的整数类型。
- 为保证公共统计连续性，消费 Token 的 `quota_data` 聚合链路必须始终记录和持久化，不得受可选的数据看板开关影响。
- 由于接口免认证，响应不得包含用户标识、Token 名称、模型名称或原始日志内容。

## 6. 验收标准

1. 未携带认证信息调用 `GET /api/public/usage/tokens` 可以进入接口处理。
2. 使用合法日期范围时，返回 `success=true`、`message=""` 和 `data.start_date`、`data.end_date`、`data.total_tokens`。
3. `total_tokens` 与指定日期范围内 `quota_data.token_used` 的汇总一致；该字段等于消费请求的 `prompt_tokens + completion_tokens`。
4. 日期按项目统一时区解析，起止日期均包含，缺少参数、格式错误、逆序日期、超过 365 天或未来日期均返回失败响应；无日志时返回 `total_tokens: 0`。
5. 接口不泄露用户、Token、模型、渠道或原始日志信息。
6. 现有认证接口和日志统计行为不受影响。
